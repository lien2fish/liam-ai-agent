# AI 導入包 提案影片

給客戶看的提案影片，**四支**：

| 專案 | 尺寸 | 長度 | 場合 |
|------|------|------|------|
| `full-wide` | 1920×1080 | 約 2:45 | 面對面提案、投影 |
| `full-tall` | 1080×1920 | 約 2:45 | 手機直接遞給對方看 |
| `short-wide` | 1920×1080 | 約 1:29 | 破冰、開場 |
| `short-tall` | 1080×1920 | 約 1:29 | LINE 傳給潛在客戶 |

旁白＝Lien 的克隆聲音（`~/聲音素材/tts/say.py`），全程第一人稱。
**完整版刻意不講金額**——留給當場依客戶規模開價。

內容依據 `line_assistant/導入手冊.md`，但角度翻轉：
那份是寫給**導入者**看的，這支是講給**客戶**聽的。

## 改稿流程

```bash
# 1. 改 script.md（旁白）與 scenes.json（字卡、圖解）
# 2. 把改過的句子刪掉，其他句子會沿用不重生
trash audio/full/s21.mp3
# 3. 重生旁白 → 重排時間軸 → 產生四支
./gen_voice.py full && ./gen_voice.py short && ./build.py
# 4. 驗發音（⛔ 這步不可跳過，理由見下）
./check_all.py full && ./check_all.py short
# 5. 版面稽核
cd full-wide && npx --yes hyperframes@0.8.30 check
# 6. 渲染
cd full-wide && npx --yes hyperframes@0.8.30 render
```

⚠️ **時間軸是算出來的，不要手改 index.html 的 `data-start`。**
`build.py` 讀每句旁白實際量到的長度來排，手改的東西下次 build 會被蓋掉。
要調節奏改 `build.py` 頂端的 `GAP_IN`／`GAP_SC`／`TAIL_SC`。

⚠️ **場景之間不要留太長的空隙。** 一開始 `GAP_SC` 給 1.7 秒，實際抽格發現
場景間會出現 1.35 秒全黑，提案影片看起來像一直斷掉。現在是 1.0 秒，
而且下一個場景在前一個淡出時就開始進場（各場景是獨立 track，可以重疊）。

⚠️ **橫式與直式共用同一份 HTML 與時間軸**，版面差異全部在 `shared/deck.css`
的 `html[data-fmt="wide"]` / `[data-fmt="tall"]` 兩組變數裡。改版型改那裡，
不要去各專案的 `index.html`（那是產生出來的）。

## ⛔ 發音一定要驗，不能只靠耳朵

2026-09-12 首次生成 33 句，**7 句有確定的發音錯誤**；改完再驗又抓到 3 句。
兩輪下來的完整清單：

| 原文 | 唸成 | 怎麼解 |
|------|------|--------|
| 漁港 | 野港 | 餵「余港」（已進替代表）|
| 客戶 | 客宿／後述／扣數 | 餵「客護」（已進替代表）|
| 資料庫 | （只聽到「庫」）| 餵「姿料庫」（已進替代表）|
| 下載 | 降載 | 改寫成「裝」 |
| 報告 | 報郭 | 改寫成「日報」 |
| 金鑰 | 金錐 | 改寫成「四組密碼」，後來整句再改掉 |
| 密碼伺服器 | 尼瑪四伏 | 改寫成「要接的東西不少」 |
| 行業術語 | 行義術語 | 改寫成「你這一行的說法」 |
| 調教 | 調校 | 改寫成「調整」 |
| 那才是 | 罵才是 | 改成「這才是」 |
| 帳號 | 講期tiu | 改寫成「名下」 |

**多數用改寫解決，不是硬湊同音字**——而且改完文案更白話，對客戶反而更好。
替代表在 `~/聲音素材/tts/發音替代表.json`，`say.py` 會自動套用，
字幕與文案一律用原字。

⚠️ **TTS 有隨機性，單次測試不足以判定。** 「客戶」測兩次錯兩次（錯法還不同），
「批貨」五次只錯一次。看到 🔴 先重生一次再驗，重複出錯才動文案。

## 檔案

| 檔 | 作用 |
|----|------|
| `script.md` | 旁白正本。**唯一的文字來源** |
| `scenes.json` | 場景：哪幾句一組、配什麼圖解、出什麼字卡 |
| `gen_voice.py` | 逐句產旁白，並量長度寫成 `audio/*_timing.json` |
| `build.py` | 讀腳本＋場景＋長度，產生四個 HyperFrames 專案 |
| `check_all.py` | 逐句丟回 Whisper 比對發音 |
| `shared/deck.css` | 設計系統（墨藍＋溫潤金，兩種版面的變數）|
| `shared/deck.js` | SVG 圖元（手機、泡泡、麥克風、堆疊、節點、打勾、紙）|

`full-*/` `short-*/` 是**產生出來的**，不要直接改。
