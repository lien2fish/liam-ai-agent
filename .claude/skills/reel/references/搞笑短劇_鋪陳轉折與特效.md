## 一、一句話原則

**開頭就讓答案入鏡，中段讓觀眾做出合理的錯誤解讀，揭曉時把視線帶回同一個道具；主笑點成立後，留住角色的反應。**

## 二、數據：短梗遠勝長劇（10 支 FB Reels）

| 長度 | 支數 | 觀看 |
|---|---|---|
| 6~7 秒單一反轉 | 3 | 21 萬~**330 萬** |
| 18~26 秒對話反轉 | 5 | 34 萬~110 萬 |
| 72~136 秒連續劇 | 2 | 2.6 萬~23 萬 |

9/10 是 AI 生成角色（固定主角「江澈」，標題直接用人名，形成 IP）；最高觀看那支看起來是實拍。

## 三、結構規律

| 項目 | 做法 |
|---|---|
| 開頭 | **0 秒就是台詞或頂部字卡**，沒有片頭 logo。句型：「本來想…結果…」「當你…時：」「當我請了一個…」，字卡全程常駐 |
| 反轉位置 | 全長的 **75~90%** |
| 反轉之後 | **留 1~3 秒反應鏡頭**；IG 那支定格約 3.2 秒（配音樂），然後循環回開場 |
| 中段 | 一個小反差換氣，再給一個新線索加壓（IG 片：先「我們不認識」→ 再「你知道我的鎖是黃色？」） |
| 剪接密度 | 短梗 0~1 刀；對話型 2~3 秒一刀（正反拍）；驚悚段 0.7~1.5 秒一刀 |
| 品牌露出 | 只有制服 logo 加一句台詞，不推銷 |

## 四、特效種類、時間點與做法

| 特效 | 時間點 | 做法 | 出處 |
|---|---|---|---|
| 頂部常駐字卡 | 0 秒到結束 | 白字黑底，設定情境或先劇透 | v01、v05、v09 |
| 推鏡放大＋角括號特效字 | 吐槽或笑點那一句 | 鏡頭推近，同時跳出〈貼臉開大〉〈貼臉吃狗糧〉〈沒救了〉 | v05 的 7–8、19–20、23–26 秒 |
| 反應推近 | 反轉之後 | 慢慢推近主角的臉，停在表情上 | v04 的 16–20 秒 |
| **笑點音樂＋定格＋紅藍彩邊** | 笑點台詞一講完 | **IG 片有聲版實測（17.3 秒錄影）**：台詞 12.72 秒結束 → **12.8 秒音樂硬進**（-12 dB，對白段完全沒有配樂）→ 約 13.0 秒畫面定格，加橘藍 RGB 分離彩邊、輕微模糊、微放大 → 定格 3.2 秒 → 16.2 秒音樂硬切 → 循環回開場 | IG 片 |
| 碎剪 | 營造緊張的段落 | 0.7~1.5 秒一刀，暴雨、跳嚇鏡頭 | v07 的 2–9 秒 |
| 背景聲 | 對白期間 | **兩種做法都有**：FB 的 AI 短劇在對白空檔仍有 -14~-17 dB 的背景聲（配樂或環境音，未分辨）；IG 片對白段只有人聲，空檔降到 -40 dB，**音樂只在笑點後出現**。⚠️ 11-22 寫的「配樂全程不斷（靜音比例 0%）」證據不足：0% 只代表沒有數位靜音，環境底噪也會是 0% | FB v02、v03、v05、v07；IG 片 |
| 音效 | 揭曉或定格那一下 | 可試一個短音效，有沒有用以試片判斷 | Codex 建議，未驗證 |

**不用的**：花俏轉場、片頭 logo、促銷字卡。

## 五、寫腳本的順序（Codex 整理）

| 階段 | 做法 |
|---|---|
| 寫劇本 | **先寫最後一句怎麼改變前面台詞的意思**，再往回寫觀眾會相信的第一個解釋。開場的道具要能在兩種解讀下都合理存在 |
| 排分鏡 | 開場拍到道具、主角與情境；中段用正反拍和反應鏡頭維持錯誤解讀；揭曉的鏡頭一次交代道具和人物的關係，用手勢、視線或手機畫面把注意力帶到答案 |
| 排笑點 | 主笑點的字幕，留到畫面足以讓觀眾看懂的那一刻才出現 |
| 驗片 | 第一次看能講出「我本來以為什麼」和「最後發生什麼」；重看找得到最早埋下的線索；**靜音也看得懂** |
