## 台股盤後日報＋早盤修正（2026-11-12 建，取代舊日報）

| 檔案 | 作用 |
|---|---|
| `market/tw_daily.py` | 資料層（證交所 MI_INDEX／BFI82U／MI_MARGN／BWIBBU_d、Yahoo 日線）＋指標＋預測＋結算 |
| `market/evening_report.py` | 21:37 晚報。`--date` 補跑、`--no-send` 本機測試、`--margin-wait 0` 不等融資 |
| `market/morning_update.py` | 08:41 早盤修正，推 LINE |
| `market/notion_daily.py` | Notion「📊 台股盤後日報」一天一頁，寫完讀回比對；失敗自動封存半成品 |
| `market/forecast_log.json` | 預測與結算紀錄（公開，只有指數數字）＋燈號狀態＋已寄送紀錄 |

**預測方法**：日報酬除以當時 EWMA 波動（λ=0.94）取近 5 年分布，再乘目前波動。早盤版＝台股報酬對前一個美股交易日費半報酬迴歸，殘差除以自身 EWMA 波動取分布。
- 2026-11-12 逐日回測：晚報隔日 80% 區間命中 79.2%（501 日）；早盤 78%（250 日）。**早盤原本用指數波動縮放殘差只有 71.6%，已淘汰，不要改回去。**

**地雷**
- 證交所 MI_MARGN 的 `融資(交易單位)` 是張數，金額要取 `融資金額(仟元)` 那列
- 證交所隔日會調整前一日的法人與融資數字（11-12 投信 125.7→123.9 億），報告是出報當下的值
- 缺資料一律判「條件不成立」，不能讓燈號因為抓不到而亮綠
- 補跑舊日期：海外只取該日以前、不改目前燈號、不推 LINE
- PDF 字型顯示不了表情符號，PDF 版把燈號換成文字
- 持股只放 Secret `MARKET_HOLDINGS`（逗號分隔的股票代號），改持股要更新這個 Secret。**任何公開檔案（含本 skill）都不要寫出實際持股**

## 回答 Lien 的股市問題（2026-11-19 建）

> 這段管「對話裡怎麼回答」，上面幾段管「程式怎麼跑」。數字一律來自報告，**不要自己估指數或預測**。

### 「給我報告」「今天的報告」
1. 報告由雲端產出、commit 到遠端，**本機常是舊的**。不要 pull（工作區常有未提交的東西），直接從遠端取：
   ```bash
   git fetch -q origin
   git -c core.quotepath=false ls-tree --name-only origin/main reports/ | grep 盤後日報 | sort | tail -1
   git show "origin/main:reports/盤後日報_YYYY-MM-DD.md" > <scratchpad>/盤後日報_YYYY-MM-DD.md && open <該檔>
   ```
2. 先講清楚**今天的出了沒**：晚報 21:37 才產出；08:41 早盤修正**只推 LINE、不產檔**；週末與休市日沒有新報告，給最近一個交易日的。
3. 公開版沒有持股。含持股的私人版只在 Email PDF 與 Notion「📊 台股盤後日報」，提一句就好。

### 解讀報告的固定順序
| 順序 | 看什麼 | 怎麼講 |
|---|---|---|
| 1 | 燈號 | 現在是哪一燈、差哪一條 |
| 2 | 指數漲跌、漲跌家數 | 一句話 |
| 3 | 三大法人，尤其外資 | 今日 vs 前 5 日平均（燈號用的就是這個比較）|
| 4 | **距年線** | 跟前一份比變近還變遠，剩幾點；這是轉紅燈的關卡 |
| 5 | 今日／5 日預測區間 | 年線有沒有落在 80% 區間內（有＝今天就可能跌破）|
| 6 | 預測有沒有失準 | 實際收盤落在前一份 80% 區間外就直說；上線樣本未滿 250 筆都算未校準 |
| 7 | 觀察清單 | 只挑跌最多／最抗跌的兩三檔 |

報告之間要**跟前一份比**（用表格並排兩天），Lien 要的是「變了什麼」，不是把報告重抄一遍。

### 燈號怎麼解釋（固定說法，規則在 `evening_report.py` 的 `rule_status`）
| 燈號 | 條件 | 意思 |
|---|---|---|
| 🔴 暫停加碼 | 連 2 日收在年線下（優先判斷）| 全部暫停 |
| 🟢 照計畫分批 | 三條件全成立：連 3 日在年線上／外資賣超小於前 5 日平均或轉買超／費半沒創 20 日新低 | 本月可投入**一批** |
| 🟡 本月這批先等 | 其餘情況 | 這批先不放 |

- 綠燈紀律：**一個月最多一批**、每批 ≤ 新增預算 20%、不用融資。綠燈連亮也只放一次。
- 燈號是**既定分批計畫的把關**，不是「該買」的訊號。缺資料一律算不成立。
- 燈號改變會自動推 LINE，Lien 不用每天看。

### 「現在適合進場嗎」
- 用燈號回答：哪一條不成立、**什麼情況會轉綠、什麼情況會轉紅**（例如「外資某天賣超低於前 5 日平均且守住年線→轉綠；連 2 日收在年線下→轉紅」）。
- 回答前先看 memory `project_investment_strategy`：Lien 的資金狀態與「不主動推投資建議」都記在那裡（**個人財務不寫進這個公開 skill**）。他沒主動說有閒錢，就提醒一句、不催配置、不給買進建議；他給了金額與風險偏好，才換算每批金額。

### 時事查證（國安基金、外資、政策、個股消息）
- 用 WebSearch（`extended`），**至少兩個來源**，優先中央社、財政部／證交所／金管會官方公告。
- **注意舊新聞被轉貼**：2026-11-17 Lien 問「國安基金是不是昨天退場」，實際上第 10 次 11-06 才進場、沒有退場決議；流傳的 PTT〈退場了！國安基金決議停止護盤〉是 2026-01-12 第 9 次的舊文。看到結論先核對發布日期與「第幾次」。
- 查不到就說查不到，列出查到的最新日期，請 Lien 給原始連結再查。
- 背景知識可補充（例如國安基金「宣布退場」與「賣完持股」可能差好幾個月），但要標出處。
- 回覆最後列 Sources 連結。

### 不做
- 不自己預測指數或給目標價——預測只引用報告裡程式算的區間。
- 不把持股、資金數字寫進公開 repo 或本 skill。
- 讓模型每天自動寫解讀（Fable／Opus 接進 workflow，估每月約 NT$700）**Lien 還在考慮（2026-11-15）**，他沒說要做就不要動手、不要催。
