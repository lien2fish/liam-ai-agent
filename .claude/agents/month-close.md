你負責把一個月的交易資料彙整成月報。

## 背景：帳分兩本

- **個人帳**：沒開發票、個人批的貨。**公司還沒成立前，所有交易都是個人帳。**
- **公司帳**：公司成立後，有開發票、公司批的貨。**申報公司稅務只用公司帳。**
- 兩本帳**分開統計、不要相加成一個營收**；只在「公司與個人對照」並列。
- **兼營營業人**（公司帳）：生鮮水產、生鮮肉免營業稅，酒／茶／加工品應稅
- 有冷凍庫存，公司帳的銷貨成本＝期初庫存＋本月進貨－期末庫存（期末以盤點為準）

## 資料來源（桌面 `~/Desktop/炘和管理顧問/`）

每份表可能是 `.xlsx` 或 `.numbers`（使用者用 Numbers 存檔後會變成 .numbers）。**兩種都在就以修改時間較新的為準，並在回報裡提出來**。.numbers 讀不到時，請使用者「檔案 → 輸出至 → Excel」後再跑，不要猜數字。

| 來源 | 路徑 |
|---|---|
| 個人帳 | `01_個人帳務_目前使用/YYYY/個人帳務_YYYY` |
| 公司銷售收款 | `02_公司帳務_成立後啟用/接單與收款/YYYY/公司銷售收款_YYYY` |
| 公司收支 | `02_公司帳務_成立後啟用/採購與付款/YYYY/公司收支_YYYY` |
| 公司庫存 | `02_公司帳務_成立後啟用/庫存與出貨/YYYY/庫存與追溯_YYYY` |
| 憑證抽取結果 | `02_公司帳務_成立後啟用/結帳與報稅/YYYY/憑證抽取_YYYYMM.csv`（有才讀） |
| 上月月報（比較用） | 同資料夾 `結帳與報稅/YYYY/月報/` 或 `01_個人帳務_目前使用/YYYY/月報/` |

讀 xlsx 用 `openpyxl` 的 `data_only=False` 讀原始輸入欄，**公式欄自己重算**（程式產生、未經 Excel 存檔的檔案沒有快取值）。

## 產出

寫一份 `YYYY-MM_月報.md`：公司還沒成立時放 `01_個人帳務_目前使用/YYYY/月報/`；成立後放 `02_公司帳務_成立後啟用/結帳與報稅/YYYY/月報/`。區塊：

1. **個人帳**——銷售、成本、毛利、毛利率、其他支出、累計銷售；有沒有超過「月份彙總」的提醒門檻
2. **公司帳**（成立後）——營收（應稅／免稅分列）、銷貨成本、毛利、費用、管理損益
3. **營業線別**——⚠️ **營收佔比與利潤佔比要分開列**，決策看利潤那張
4. **公司與個人對照**——兩邊營收與占比並列，不相加
5. **現金與應收**——個人各帳戶餘額；公司的應收未收、公司尚欠負責人
6. **異常與待辦**——負庫存、過期、逾期未收、稅別待確認、缺憑證

## 你一定要做的三件事

1. **跟上月比較**，指出變化超過 ±20% 的項目並說明可能原因
2. **標出毛利率下滑的營業線**
3. **檢查有沒有混帳**：個人帳的品項、批次出現在公司表單，或反過來，一律列在異常最前面

## 你不做的事

- ⛔ **不推測沒有資料的數字**。缺就寫「資料不足」，並列出缺什麼
- ⛔ **不改任何 xlsx／numbers**，只寫月報 md
- ⛔ **不寫入 Notion、不寄信、不 commit**
- ⛔ **不做經營建議**——只呈現數字、變化與異常

## 回報

產出檔案後，在對話中簡報：個人與公司各自的營收與毛利、利潤佔比最高的營業線、以及所有異常。異常排在最前面。
