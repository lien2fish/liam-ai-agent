# 大圖 CMYK 送印

程式產生的大圖要送印刷廠時，會踩到一批印刷業特有的陷阱。
下面每一條都是印壞或差點印壞換來的。

---

## ⚠️ 不要交 CMYK TIFF

**RIP 可能把它反相成負片。** 實際發生過：整批輸出出來油墨反相，
整面布變負片，重印一次的成本遠高於多花半小時換格式。

**改交自組的 CMYK PDF：**

| 項目 | 做法 |
|------|------|
| 版面尺寸 | 用 **1:10** 縮放（PDF 座標單位有上限，實體尺寸直接寫會爆） |
| 影像 | **內嵌全尺寸點陣圖**，標稱 72dpi，靠版面縮放還原實際 dpi |
| 色彩空間 | `DeviceCMYK` |
| 壓縮 | `Flate`（無損。JPEG 壓縮在大面積純色會出現色塊） |

TIFF 只當**中繼格式**，RGB PNG 留著當預覽與存檔。

---

## ⚠️ 驗色不能用 `(1-C)(1-K)` 近似式

那條公式會把顏色算得離譜。實測：同一個綠色，
近似式算出 `(51,228,12)`、實際 `(32,154,75)`——**差 76**，
看起來像大爆色，其實是公式錯了。

**要用同一支 ICC profile 反轉回 sRGB 再量：**

```python
from PIL import ImageCms
rgb = ImageCms.profileToProfile(cmyk_img, cmyk_profile, srgb_profile)
```

### 殘差多少算正常

反轉回來跟原始 RGB **差 20~30 是 CMYK 色域極限**，不是流程有誤。
飽和度高的品牌色（鮮綠、螢光橘、寶藍）印刷本來就印不到，
在螢幕上看到的那個亮度不存在於油墨裡。

**先跟客戶說明，不要等打樣出來才解釋。**

## 解析度

大圖不需要 300dpi。觀看距離越遠，需要的 dpi 越低：

| 用途 | dpi | 說明 |
|------|-----|------|
| 手持印刷品 | 300 | |
| 室內看板、近距離 | 150 | |
| **外牆防水布、遠距大圖** | **100** | 25 公尺的布用 300dpi 會產生無法處理的檔案 |

換算：`像素 = 公尺數 × dpi × 39.37`。
先用 100dpi 算出像素量，檔案大到跑不動就往下調，不要反過來。

---

## 出血、裁切、安全線

| 區域 | 規則 |
|------|------|
| 出血 | 四邊各**多做 1cm**，背景色/圖延伸出去 |
| 裁切線 | 成品邊界 |
| 安全線 | 內縮 **2~3cm**，文字與 logo 不可越線 |

**繩孔、魔鬼氈、車邊會再吃掉邊緣**，防水布類的安全線要留更多。
送印前問清楚廠商的加工方式。

---

## 字級要比你以為的大

螢幕上看起來夠大的字，印成 25 公尺的布會小到看不見。

**用觀看距離回推**：最小字高 ≈ 觀看距離 ÷ 200。
5 公尺外要看清楚 → 字高至少 2.5cm。

實務上程式產圖時**字級普遍設太小**，因為是照螢幕比例調的。
輸出前把圖縮到手機大小看一次——那大概就是遠看的效果。

---

## 異形版面（梯形、斜切、不規則）

現場量到的尺寸**彼此會矛盾**，因為量斜邊很難量準。

**做法：挑最可信的邊當基準，用幾何反推其他邊，不要三個量測值都採信。**

實例：一面直角梯形牆，量到的斜底是 325cm，但用兩個直邊與高反推出來是 338cm，
差了 13cm。**採信直邊反推的值**——直邊好量、斜邊不好量，而且幾何上鎖死了。

照量到的 325 做，裝上去會短一截。

## 送印前檢查清單

| 檢查 | 為什麼 |
|------|--------|
| 用手機大小看一次 | 字級是否足夠 |
| 逐頁確認沒有內部資料 | 成本、進價、客戶名、內部代號 |
| 確認字型有嵌入或轉外框 | 廠商機器沒有你的字型 |
| 中日文標點是否變成豆腐方框 | 某些字型缺 `・`(U+30FB)、`／`(U+FF0F)，要先替換成 `·` `/` |
| 檔名不含版本字樣 | 「最終版_v3_真的最後」會被印上去或造成拿錯檔 |
| QR code 用手機實掃 | **不要相信「產生時是對的」** |

### QR code 一定要實掃

程式產生的 QR 即使 URL 正確，也可能因為**印刷解析度不足、對比不夠、
或被裁切線切到**而掃不出來。

就地替換舊 QR 時特別危險：新碼比舊碼小的話，**舊碼的殘影會留在邊緣**，
掃描器會讀到混合圖案。替換後要把整個舊區域清成底色。

## 交件

| 給廠商 | 自己留 |
|--------|--------|
| CMYK PDF（送印檔） | RGB PNG（預覽、存檔、日後改圖的母檔） |

**改圖一律從 RGB 母檔重出**，不要在 CMYK 檔上改——每轉一次色彩空間就掉一次色。

局部替換（換一個名字、換一張照片）時，**交整面重出的檔案，不要交補片**。
廠商拼接補片的對位誤差會比重印一整面貴。
