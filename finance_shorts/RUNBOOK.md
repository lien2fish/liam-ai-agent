# 金錢怪物：無人值守做一支長片

Lien 說「做金錢怪物」時照這份做完整流程（每週兩次；2026-10-23 決定先不設自動開工，
品質穩定後再談）。Lien 2026-10-22 把頻道全權交給 Claude 經營，**目標是開始有廣告收益**。
做到上片排程就結束；**Lien 開了對話通常就離開了，不要停下來問問題**——卡住就照最後一節回報。

## 收益目標（決定一切取捨）

- 2027-01-31 前：1,000 訂閱＋12 個月內 4,000 小時觀看時數
- 2027-02-01 起新申請者要 8,000 小時。**Shorts 觀看不算進時數** ⇒ 主力是長片

## 內容原則（Lien 定，不可違反）

1. **講主題國家本身，重點是對一般人生活的影響**（房貸、物價、薪水、工作、存款、旅遊）——不是市場分析
2. **不必每支都跟台灣比**，有自然的連結才提
3. **非投資建議**：不講買賣、不預測價格、不說「應該」；看法要明講「我們的看法」
4. 開場固定「金錢怪物，一睜眼就是錢的世界。」，結尾固定片尾頁「關注我，給你更多錢的大小事。」
5. 長度 **8～12 分鐘**（1.2 倍速後）。開場 30 秒內要有具體數字＋懸念

## 步驟

### 1. 選題（看 `finance_shorts/題目紀錄.md`，不重複）

- 🔴 **先看熱搜**（Lien 2026-10-23 定）：台灣 Google 熱搜（trends.google.com/trending?geo=TW）、
  YouTube 台灣熱門、新聞熱門話題。**熱搜裡跟「錢」扯得上關係、能講到對一般人生活影響的，優先做**——
  觀眾已經在找這件事，點進來的機率最高。熱搜沒有合適的，再找下面的
- 找**過去 7 天**全球的錢事件：央行、物價、房市、匯率、罷工、稅、能源、大企業裁員
- 🔴 **類似主題、同一個國家，發布時間不能太接近**（Lien 2026-10-23 定）：
  對照 `題目紀錄.md` 已公開與排程中的，**同國家或同主題類別（例：升息／房貸）至少隔 14 天**，
  相鄰兩支要國家和主題都不同。jp-01 就是因為跟 mw-01 都是升息＋房貸而撤掉排程
- 挑「一般人會被影響、而且影響講得清楚」的。畫面要找得到素材（那個國家的街景、CC 影片）
- 寫進 `題目紀錄.md`：日期、題目、為什麼挑、集數編號（國家代碼-序號，如 `de-01`）

### 2. 查證 → `facts.json`

- **每條事實 ≥2 個獨立來源，其中至少 1 個官方原文**（央行、統計局、政府公告）
- 每條要有 `claim`、`tokens`（句子裡會出現的所有數字）、`sources`（`name`／`url`／`official`／`quote` 原文摘句）
- 只有媒體轉述官方數字的，口播要講明「據 XX 統計、多家媒體報導」
- **相對時間一律換成日期**（不寫「這週」「下週」）
- 時事的因果歸因**以官方說明為準**，不自己推論原因

### 3. 寫腳本 → `scripts.json` 的 `episodes.<集>`

照 `fr-01` 的格式：`format: slides`、`aspect: 16:9`、`tts: clone`、`speed: 1.2`、`lang: zh`。
每句 `text`（字幕）、`facts`、`pool` 或 `clips`（畫面）、`screen`（大數字卡）。

**`say`（餵給克隆聲音的字）一定要另外寫**——規則在 voice-clone skill：
- 阿拉伯數字全部寫成中文（「9 月」會唸成「酒味」）；日期用「號」
- 英文品牌與人名用中文音譯
- skill 裡「改寫文案」那張表的詞直接換說法

### 3.5 結構與剪輯（2026-10-27 拆解窮奢極欲三支 8 分鐘長片後定）

| 時間 | 該有什麼 |
|---|---|
| 0:00 | 固定開場（金錢怪物，一睜眼就是錢的世界。） |
| 0:04～0:20 | **一個具體的驚人數字或故事**，外幣一律換算新台幣（例：車牌 5,500 萬迪拉姆＝新台幣 4.6 億） |
| ～0:30 前 | 反差提問＋「這一集我們就來…」宣告題目 |
| 前 2 分鐘 | 背景＋**用大家熟悉的東西比規模**（相當於整個歐盟人口、台北 101 的 4.8 倍）；接著講出這集的分析框架（例：三個面向） |
| 中段 | 依框架逐段講，每段用路標句開頭（「先看…」「接著看…」「第三…」） |
| 結尾前 | **回扣開場**（「開頭提到的…」），再講「我們的看法」 |
| 結尾 | 總結＋往後觀察什麼＋留言提問＋片尾 |

- 畫面節奏：**實拍片段每個鏡頭約 2.5 秒**（窮奢中位數 2.2～2.5 秒；我們 tw-01 約 4～5 秒）。靜態圖可以用慢推鏡，一張約 4～5 秒
- **證據上畫面**：官方文件、公告、統計表的截圖加紅框標重點（窮奢台中那支用公司登記資料截圖）——我們的事實本來就有官方原文，截出來就是最有說服力的畫面
- 右上角整支片掛這集的提問標籤
- 查不到的傳言直接講「無從證實，這裡不帶入」（窮奢也這樣做），不要硬塞
- ⛔ 不學的：新聞台／YouTuber 片段（版權風險，窮奢是靠「有版權問題請通知」在扛）、「資料未能一一查實」的寫法

### 4. 查核：`python3 finance_shorts/verify.py <集>`，沒過不准往下

### 5. 素材

- 照片：`commons.py search／take`（只收公有領域／CC0／CC BY）
- 影片：`broll.py search／peek／take`（只收 YouTube 創用 CC）。**有別人浮水印、像合輯的不要**
  - `take` 的長度一律 **8 秒**：每句的段數是「句長÷4.8」四捨五入，單段最長要 7.2 秒，剪 6 秒渲染時會直接中止
  - 剪完一定抽格看（中間＋第 7 秒）：**近距離人臉、原作者疊字／浮水印、畫面裡看得到的舊價格**（油錶、價目牌）一律放進 `reject`
  - 素材地點要對：別國的加油站品牌、別國的街景不能當成這集的國家
- 抗議／災害這類畫面若是舊影像，`ep.note` 寫「示威畫面含資料畫面」，上片時 `youtube.json` 的 `notes` 寫明年份

### 6. 配音與渲染：`python3 finance_shorts/slides.py <集> --render`

產出在 `<集>/renders/final_1.20x.mp4`，複製到 `試做成品/<集>_<短標題>_金錢怪物.mp4`。

🔴 **渲染規則**：所有產線共用，寫在 `CLAUDE.md`「HyperFrames 本機渲染規則」。`slides.py`／`build.py`／`podcast*.py` 都已經改成呼叫 `tools/hf_render.py`（抽格限流＋`--sdr`＋`--workers 3`），**不要另外手打 `npx hyperframes render`**。

- 這條產線就是事件源頭：es-01 有 186 段 b-roll，2026-10-27 兩度吃光記憶體、整台重開；其中一段 `es_tour_10a.mp4` 是 HDR，害整支片變慢又發灰
- 渲染一律**背景跑**；崩過一次**不要原樣重跑**
- 驗收加一條：`ffprobe -show_entries stream=color_transfer` 要是 `bt709`，不是就別上片

### 7. 自己驗收（全部要過才上片）

- 配音先跑 `python3 finance_shorts/tts.py <集>`，再跑 `python3 finance_shorts/check_vo.py <集>`（整集 large-v3 回聽，**逐句比對數字**）。
  🔴 確定唸錯 → 改那句的 `say` 重跑 tts（只會重產改過的句子；`say` 不變只想重抽一次，才刪 `<集>/audio/l<句>.mp3`），再 `check_vo.py <集> <句>` 驗；
  ⚠️ 小數點待確認多半是 Whisper 寫法不穩，`say` 裡有寫「點」就可以放行。
  （`check_say.py` 把數字差異歸為可忽略，數字等於沒驗，所以整集驗收不要用它）
- 抽 6 格以上畫面看：字幕有沒有貼邊、畫面跟句子對不對得上、有沒有黑畫面
- **最後一格一定要是片尾卡**（最後一句 `screen` 要 `kind: outro`，不能寫 `broll`／`pool`）——es-01 漏掉，多渲染一次
- 總長 8～12 分鐘

### 8. 上片：寫 `<集>/youtube.json`（格式看 `jp-01/youtube.json`），然後

```
python3 finance_shorts/publish.py <集> --dry-run   # 先看說明欄
python3 finance_shorts/publish.py <集>             # 排程隔天 18:00，自動傳 LINE 給 Lien（10-26 起 Claude 自己執行，Lien 授權全程安排上傳與排程）
```

- 標題 ≤30 字、要有數字和懸念；章節至少 3 個、間隔 ≥10 秒
- hashtag 由程式檢查 ≤15

### 8.5 Shorts：每支長片切 3 支（2026-10-26 起）

- 寫 `<集>/shorts.json`（格式看 `tw-01/shorts.json`），跑 `python3 finance_shorts/make_shorts.py <集>`
- 每支要有**專為 Shorts 寫的開場鉤子**（`hook`）：第一句直接問觀眾或丟反直覺事實，答案在片中，不誤導；畫面借最有衝擊力的大數字卡
- `hook.say` 一樣要套發音替代字（颱風→台風、老闆→老版…），**產完用 Whisper 回聽開場**，唸錯就刪 `audio/hook_*.wav` 重產
- 驗收要用 **macOS 原生解碼**（`afconvert` 轉 wav 再量各時間點音量）——Whisper 讀得到不代表播放器有聲音（10-26 單聲道接立體聲，播放器 3 秒後無聲）
- 上片資料寫在每支的 `yt`（title／summary／hashtags／tags），**長片傳完才能傳 Shorts**（說明欄要附完整版連結）：
  `python3 finance_shorts/publish.py <集> --short a --dry-run`，再拿掉 `--dry-run`
- 發布時間自動對齊長片：A 同時、B +2 天、C +4 天（`--at` 可覆寫）；傳過的 video_id 會寫回 shorts.json，重跑會擋
- ⚠️ **每日上傳有上限**（頻道沒電話驗證）：回 400 `uploadLimitExceeded` 就是今天額度用完，在上傳初始化就失敗、不會產生影片，隔天重跑同一行即可。2026-10-27 長片＋1 支 Short 後就撞到（前一天傳了 8 支）
- Short 的說明欄**不吃 `notes`**（只有長片會讀）；舊示威畫面的聲明直接寫進該支的 `summary`

### 9. 收尾

- `題目紀錄.md` 補上 video_id、發布時間
- 新踩到的唸錯詞，寫進 voice-clone skill（`.claude/skills/voice-clone/SKILL.md`）

## 成長策略（2026-10-26 Claude × Codex 討論兩輪定案）

- **主打 Shorts 系列《錢的誤會》**：一支拆一個大家信以為真的金錢說法，30～45 秒，**Shorts 本身給完整答案**（不靠吊胃口逼導流）
- **獨立 Shorts 先從既有長片切**：fr／uk／jp／mw 的研究已過雙來源查證，切成不同主題的獨立 Short，不用新查證；但新鉤子、剪掉的條件、過時的「現在／今年」仍要核對
- **14 天間隔只管長片選題**，Shorts 可例外；但同類題（美國房貸／日本房貸）的 Short 要錯開，不連發
- 節奏：每週 1～2 長片＋3～4 Shorts；長片結尾預告下一集的具體問題
- **Shorts 說明欄連結點不了**，Studio「相關影片」API 設不了——**Lien 10-26 說不用設**，不要再請他手動設
- **判斷方法（樣本小，看排序不看門檻）**：每支記錄發布後 72 小時＋第 7 天的選擇觀看率／滑走率、平均觀看百分比與秒數、歸因訂閱數。前兩項都排前三的題材，再做兩支；有帶來訂閱的優先。第一輪：颱風 3 支＋其他 4 支，共 7 支，2 週後檢討

## 卡住的時候

任何一步做不下去（查不到官方來源、素材找不到、驗收一直不過、工具報錯）：

1. **不要上片、不要硬湊**
2. 用 `~/bin/gh workflow run line_notify.yml -f text="🔴 金錢怪物今天沒做成：<原因一句話>"` 通知 Lien
3. 把做到哪、卡在哪寫進 `題目紀錄.md`，下一次開工可以接著做
